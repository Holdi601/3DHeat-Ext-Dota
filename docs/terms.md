# Terms and licence

## Valve's map

Dota 2 and its map belong to Valve, who do not endorse this project. This tool
ships nothing of the game and downloads nothing: it reads the files of the
copy **you** installed, on your machine, through Source2Viewer, outside the
game. It changes nothing in the game and talks to no server. The level it
writes is a derivative of Valve's map: it is yours to view in the 3DHeat
viewer, not to share or publish. Using the tool is your decision, under the
terms you accepted for Dota 2 and Steam.

That is why it is a separate package: if Valve ever asks for it to go, it
goes alone, and the viewer, the Watcher and the other tools stay.

## Source2Viewer

Reading Source 2's compiled files is done by Source2Viewer's command line
(ValveResourceFormat, MIT licence,
[github.com/ValveResourceFormat/ValveResourceFormat](https://github.com/ValveResourceFormat/ValveResourceFormat)).
It is not part of this tool and not bundled with it: you download it
yourself, and this tool only runs it. See
[`LICENSES.md`](https://github.com/Holdi601/3DHeat-Ext-Dota/blob/main/LICENSES.md).
