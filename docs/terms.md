# Terms and licence

## Valve's map

3DHeat Dota is not affiliated with or endorsed by Valve. Dota 2 and related
names and trademarks belong to their owners. This tool ships nothing of the game
and downloads nothing: it reads the files of the copy **you** installed, on your
machine, through Source2Viewer, outside the game. It changes nothing in the game
and talks to no server. The level it writes stays on your machine, for you to
view in the 3DHeat viewer.

## Its own project

Each game reader is its own small project with its own licence file, releases
and issue tracker, so it can be installed, updated, maintained - or withdrawn on
a rights holder's request - on its own, without affecting the viewer or the
other tools.

Rights holders: open an issue at
[3DHeat-Ext-Dota/issues](https://github.com/Holdi601/3DHeat-Ext-Dota/issues) -
we respond quickly and remove anything on request.

## Source2Viewer

Reading Source 2's compiled files is done by Source2Viewer's command line
(ValveResourceFormat, MIT licence,
[github.com/ValveResourceFormat/ValveResourceFormat](https://github.com/ValveResourceFormat/ValveResourceFormat)).
It is not part of this tool and not bundled with it: you download it
yourself, and this tool only runs it. See
[`LICENSES.md`](https://github.com/Holdi601/3DHeat-Ext-Dota/blob/main/LICENSES.md).
